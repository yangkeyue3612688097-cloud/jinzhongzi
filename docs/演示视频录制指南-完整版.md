## 一、录前准备（开录前 10 分钟做一遍）

1. **双击桌面 `start-local.bat`** → 黑窗口依次打印 `[1/6] MySQL` → `[2/6] 检查/启动本地链` → `[3/6] 部署合约（若复用链则跳过）` → `[4/6] 后端` → `[4.5/6] 自动重锚存证` → `[5/6] 前端` → `[6/6] ComfyUI` → **`ALL READY`**（约 1–2 分钟）。黑窗口全程**不要关**，可最小化。
   > **新版脚本已修好两个复发问题**：① 若 8545 上已有链在跑，会显示 `REUSING it. Anchors are preserved.` 并**复用旧链、跳过部署**，重跑脚本不再把链清零；② 后端起来后会自动执行 `reanchor.ps1`，把数据库里所有作品存证重新锚定到当前链，历史数据不会显示"链上复核未通过"。
   > 桌面副本已于 2026-11-09 同步为最新版（旧副本已备份为 `start-local.bat.bak-20261109`）。**务必用最新的这一个**——旧副本缺少 ComfyUI 跨域修复，且每次都会重置链。
2. 双击 **`演示前自检.bat`**，五项全 OK 再开录（第五项 ComfyUI 8188 现在是必检）。
3. 开两个浏览器窗口：
   - 普通窗口 → 打开 `http://127.0.0.1:5173` → 登录 `demo / 123456`
   - 隐身窗口（Ctrl+Shift+N）→ 同地址 → 登录 `partner / 123456`
4. 桌面放一张演示图（命名 `落日飞鸟.jpg`，任意图都行；工作区 `uploads\294e7a1b80f543e8ad53d070e246f921.jpg` 是现成海边飞鸟图，可直接复制用）。
5. 录屏：1080p、只录浏览器区域；开系统"专注/勿扰"防弹窗；关掉无关标签页。

## 四、翻车点与补救
| 症状 | 原因 | 处理 |
|---|---|---|
| 页面打不开 | 黑窗口被关 | 重新双击 `start-local.bat` |
| 邀请报错"不能邀请自己" | 下拉选成 demo | 重搜选 `partner` |
| 生成协议按钮灰色 | 比例合计≠100% | 改 60+40 |
| 【按协议分配收益】灰色 | 没有"待结算"收入事件 | 先创建订单并确认收款 |
| 链上状态 pending/未上链 | 本地链卡 | 详情页点【重试上链】；不行跑 `演示前自检.bat` 看 8545 |
| 验证页显示「链上复核未通过 / No matching anchor exists on chain」 | 本地 Hardhat 内存链被重置，链上锚点清空但 MySQL 记录还在 | **按 F5 刷新**；若仍红，双击工作区根目录 `reanchor.ps1`（或重跑 `start-local.bat`，它会自动重锚）。注意：链重置后同一私钥重发同一交易会生成**一模一样的 txHash/区块号**，别被"看起来一样"骗了，以「链上复核」那一行颜色为准 |
| 隐身窗口串成 demo 登录态 | 账号串了 | 隐身窗口退出重登 partner |
| 弹红色报错横幅（非防重复那次） | 偶发请求失败 | 等 2 秒刷新，重来当前步 |
| 本地生成读不出模型 | ComfyUI(8188)没起 | 重跑 `start-local.bat` |
| 录屏出现系统弹窗 | 通知干扰 | 开勿扰后重录该镜头 |
| 想结束录制 | —— | 录完最后一步，先停录屏，**最后再关**黑窗口（直接关窗口或 Ctrl+C） |
