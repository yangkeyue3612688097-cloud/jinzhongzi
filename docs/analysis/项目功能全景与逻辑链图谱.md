## 四、核心逻辑链（两条主线，全程真实上链）

### 主线 A：作品确权存证链
```
上传图片(WorkUpload)
   → 计算 SHA-256 文件指纹(dataHash)
   → 落库 ai_work + evidence
   → EvmEvidenceChainGateway 调 BusinessAnchor.anchor()
   → 交易上链(区块 N)，返回 txHash
   → 回写 evidence.tx_hash / block_number
   → WorkDetail 显示「已上链」+ 可下载证书 PDF
   → Verify 页：输入/粘贴 dataHash → 查链上哈希 → 拖原图比对通过
```
**代码位置**：`AiWorkServiceImpl` → `EvmEvidenceChainGateway` → `BusinessAnchor.sol`；表 `evidence` + `chain_anchor`(outbox 重试)。

### 主线 B：协作分润闭环链（项目核心亮点）
```
发起邀请(WorkDetail→选 partner，⚠不能是自己)
   → partner 在 Invites 接受
   → Collaboration 生成协议(协商比例，合计必须 100%，如 60/40)
   → 协议哈希上链(区块 N+1)
   → 双方确认(2/2)→协议生效
   → 客户下单 license_order(金额，如 800)
   → 项目方确认收款 confirmReceipt
   → 自动生成 revenue_event(绑定协议版本 v1)
   → 按协议分配收益 settlement_receipt(凭证上链,区块 N+2)
   → profit_record 写入分账明细(partner 到账 800×40%=320)
   → 凭证页显示交易哈希；再点分配触发防重复拦截
```
**代码位置**：`CollaborationInviteServiceImpl` → `CollaborationAgreementServiceImpl` → `CollaborationServiceImpl`(createOrder/confirmReceipt/settle)；表 `collaboration_agreement` / `license_order` / `revenue_event` / `settlement_receipt` / `profit_record`。

### 主线 C：本地 AI 生图闭环（技术含量镜头）
```
LocalGenerate 输入提示词(步数1/CFG1/512)
   → 前端经 /comfy 代理 → ComfyUI 8188 出图(CPU ~20s)
   → 图落盘 uploads/
   → 自动算图指纹 → 视同作品走主线 A 上链存证
   → 直接进 Verify 验证闭环
```

### 链层容错机制
`chain_anchor` 表作为 outbox：上链失败的任务留待后台重试，保证「业务成功 ≠ 链上丢失」。
