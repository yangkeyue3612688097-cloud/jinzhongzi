# 区块链 AI 可信存证与协作分润平台 — 项目总览

> 大创项目 / 金种子大赛参赛作品。本文档为顶层总览，面向队友与评审，串联其余文档。

## 1. 项目定位
面向 **AIGC 创作者与协作小团队** 的可信存证平台：把 AI 生成作品的内容哈希、生成参数、作者身份签名**锚定到区块链**，并对外提供**无需登录的公开验证页**，解决「作品是谁在何时用什么参数创作、是否被篡改」的权属证明问题；同时支持多人协作创作的贡献留痕与分润结算。

## 2. 技术栈
- 前端：Vue 3 + Vite + Element Plus
- 后端：Spring Boot (Java 17) + MyBatis
- 区块链：Hardhat 本地 EVM 测试链 + `BusinessAnchor` 极简锚定合约（web3j 直连）
- AI 生成：本地 ComfyUI（CPU 模式，sd_turbo 模型）
- 数据库：MySQL 8.0（独立 3307 实例）

## 3. 一键启动
双击桌面 **`start-local.bat`**，黑窗口依次打印 `[1/6] MySQL` → … → `[6/6] ComfyUI` → `ALL READY`，然后浏览器打开 **http://127.0.0.1:5173**。
录制/演示前建议先跑 **`演示前自检.bat`** 确认五项服务全 OK。

测试账号：
- 创作者：`demo / 123456`
- 协作者：`partner / 123456`（用浏览器隐身窗口登录，模拟第二人）

## 4. 核心闭环（已端到端验证）
1. **创作**：上传图片，或「本地生成」调用本机 ComfyUI 出图。
2. **存证**：作品详情页「上链存证」→ 计算内容哈希 → 平台托管私钥签名 → 写入 Hardhat 链，返回 `txHash` 与区块号。
3. **公开验证**：任何人访问 `/verify/{dataHash}`（无需登录）即可看到来源清单、存证证书，并对链上回执做三层核验。

> 验证证据：历史实测 `txHash=0x97a0be8f…`、`blockNumber=5`、`chainStatus=1`，向 Hardhat 查询该回执真实存在、状态成功、写入合约 `0xCf7Ed3…FB0Fc9`。

## 6. 已知边界（诚实声明，答辩请如实说明）
| 项 | 现状 | 说明 |
|---|---|---|
| 上链环境 | 本地 Hardhat 测试链 | 链可重置，**非第三方公信链**；生产应切换司法链/联盟链/测试网 |
| 上链内容 | 仅哈希锚定 | 不在链上存原文/图片，符合成本与隐私惯例 |
| 身份模型 | 平台托管私钥 | 用户不持有私钥；降低门槛，但「链上身份」属平台代持 |
| 协作分润 | 链下记账 + 待上链锚点 | 分润为数据库记账与「已付款」标记，链仅做确权锚定，未做智能合约自动分账 |

## 7. 答辩要点
- **重点讲**：创作→哈希→平台签名→上链→公开验证的端到端闭环；来源清单比单纯存图更有版权说服力；第三方无需登录即可核验。
- **谨慎讲**：「区块链分润」建议表述为「链上确权 + 链下结算留痕」；本地链如实说明是演示环境。
- **可补强**（如需提升含金量）：切换真实测试网/司法链、分润用智能合约 escrow 自动打款、身份模型统一为自托管。
