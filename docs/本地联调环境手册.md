## 六、踩过的坑（记住，下次不用再踩）

1. **shell 代理劫持 localhost**：本环境 curl 默认走 `http://127.0.0.1:53456` 代理，测试本地接口要加 `--noproxy '*'`。
2. **SERVER_PORT 环境变量**：启动器注入了 `SERVER_PORT=49270`，起后端必须显式 `--server.port=8080`。
3. **Windows curl 不认 `/tmp`**：`-F file=@/tmp/x.png` 会报 exit 26，要用 `C:/...` 绝对路径。
4. **URL 里的中文必须百分号编码**，否则 Tomcat 直接 400/500。
5. **web3j 编码 bytes32 必须用 `generated.Bytes32`**，不能用 `DynamicBytes`（动态数组编码，ABI 对不上）。
6. MySQL 数据想重置：停掉 3307 进程，删 `mysql-data2` 目录，重新 `--initialize-insecure`。

> 注：原 `mysql-data` 目录已损坏（系统库目录丢失，MySQL 无法启动），现统一改用 `mysql-data2`（另一个可用实例）。`start-local.bat` 与 `_mysql_start.bat` 已更新指向 `mysql-data2`。
7. **bat 文件里不要写中文注释**：cmd 按 GBK 解析 UTF-8 的 bat 会把命令行撕碎（报“'m' 不是内部或外部命令”）。所以 `start-local.bat` 全部用英文注释。
