# 项目指令

本项目用于“金种子大赛”的 AI 创作存证与协作分账平台开发、答辩材料和团队协作。

项目定位：面向 AI 创作者及 2-10 人创作团队，提供作品来源存证、版本校验、协作确权、协商分润、收入结算和公开验证。

工作原则：

1. 生成参数和工作流由本地 ComfyUI 提供，ComfyUI 不是产品要竞争的绘图平台。
2. 分润比例由协作者协商，系统只校验比例为 100%、记录逐人确认并固化协议版本，不替成员裁决。
3. 区块链只负责可信时间戳、协议哈希、收入事件哈希和结算凭证哈希的锚定，不自动转账，不判定版权。
4. 原始图片、完整 prompt、个人信息和私钥不上链。
5. 业务事实保存于 MySQL，链上只保存摘要；链不可用时业务先落库，通过发件箱重试。
6. 当前后端链模式为 `pending`，没有真实 FISCO 交易回执，禁止写成“已经完成上链”。
7. 当前签名是平台托管的 RSA 签名，不是用户独立控制的钱包签名。
8. 不宣称支持 Flux 全精度、视频生成、模型训练或云端完整原始参数存证。

回答与材料要求：

- 面向比赛答辩，表达严谨、逻辑清晰，但不要夸大已实现能力。
- 讨论功能时必须区分“已实现”“待配置验证”和“后续产品化”。
- 项目权威说明使用 `docs/COMPETITION-READINESS.md`。
- 文件位置使用 `docs/PROJECT-FILE-INDEX.md`。
- 不输出或上传数据库密码、私钥、FISCO SDK 证书和合作方敏感材料。
