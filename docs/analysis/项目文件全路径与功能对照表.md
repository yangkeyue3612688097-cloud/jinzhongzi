## 7. 主线数据流（对着文件看更清楚）

```
WorkUpload.vue 上传作品
   → AiWorkController → AiWorkService → HashUtil 算哈希
   → EvidenceService 落 evidence 表 + chain_anchor 表（outbox）
   → EvmEvidenceChainGateway(web3j) → BusinessAnchor.sol @ Hardhat:8545
   → 返回 txHash → 回写 chain_anchor

Invites.vue 邀请 → CollaborationAgreementService 协商比例 → 协议哈希上链
   → 客户下单(LicenseOrder) → 确认收款 → RevenueEvent(收入事件)
   → SettlementReceipt(结算凭证) → ProfitRecord(分润明细)

Verify.vue 公开验证页：凭 dataHash → PublicEvidenceController → 查库 + 查链
```
